# Bensocial Telegram Bot

Naira wallet + product catalog + orders + OPay integration placeholders.

## 1. Install

Python 3.10+ is recommended. aiogram is an async Telegram framework. See the official docs:
https://docs.aiogram.dev/en/latest/

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## 2. Configure

Copy `.env.example` to `.env` and fill in:

- BOT_TOKEN: use a NEW token generated by @BotFather
- ADMIN_IDS: comma-separated Telegram IDs
- OPay merchant credentials
- OPay webhook URL
- Supplier API credentials

Never commit `.env`.

## 3. Database

SQLite works for development:

DATABASE_URL=sqlite+aiosqlite:///./bensocial.db

For PostgreSQL, use:

DATABASE_URL=postgresql+asyncpg://USER:PASSWORD@HOST:5432/bensocial

## 4. Seed demo products

```bash
python seed.py
```

## 5. Run bot

```bash
python -m app.main
```

## 6. Run webhook

```bash
uvicorn webhook:app --host 0.0.0.0 --port 8000
```

Your public HTTPS endpoint should be configured in the OPay merchant dashboard.

## Payment security

OPay documents a staging and production payment-create endpoint and supports callbacks. Callback notifications should be verified and the payment status should be checked before crediting a wallet.

Do not trust screenshots or user-supplied "successful" messages.

## Supplier adapters

`app/suppliers.py` deliberately contains placeholders. Add only documented APIs from legitimate providers. Do not use the bot to bypass OTP/KYC, evade platform safeguards, or facilitate fraud.

## Admin

This starter includes the database model and admin ID configuration but does not expose destructive admin operations yet. Add an authenticated admin router for product CRUD, order management, refunds and broadcasts before production use.
